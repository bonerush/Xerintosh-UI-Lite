Xeros 内核架构：FreeRTOS → Bare-Metal 迁移

方案 B：调度核心重写，保持 VFS / Device / HAL / App 层不变

◀ 当前架构（FreeRTOS 依赖）
不变 App 层 (ui_task, wifi, apps)
不变 HAL 层 (display, input, uart, power)
不变 Xeros VFS + Device Model
小幅改 kern_task (TCB 管理)
小幅改 kern_sched (调度循环)
重写 kern_port (令牌协议→真正的上下文切换)
↓ 依赖 ↓
移除 FreeRTOS (xTaskCreate, vTaskDelay, Semaphore)
移除 GPTimer ISR
▶ 新架构（Bare-Metal）
不变 App 层 (ui_task, wifi, apps)
不变 HAL 层 (display, input, uart, power)
不变 Xeros VFS + Device Model
小幅改 kern_task (新 TCB 字段，栈自管理)
重写 kern_sched (O(1) 优先级调度器)
新增 kern_runq (Per-CPU 就绪队列 + bitmap)
新增 kern_ctx (Xtensa 汇编上下文切换)
新增 kern_sync (spinlock / mutex / sem)
↓ 硬件层 ↓
新增 CCOMPARE0 定时器 (每核独立)
新增 核间中断 IPI

新增 / 重写模块总览

kern_ctx — 上下文切换

  • Xtensa LX6 完整寄存器保存/恢复（32 GPR + SAR + Loop + PS）
  • 汇编实现 kern_ctx_switch(from, to)
  • 栈溢出 canary + guard page（MPU）

kern_runq — Per-CPU 就绪队列

  • 32 级优先级 bitmap，O(1) 查找最高优先级
  • 每优先级 FIFO 队列，O(1) 入队/出队
  • Per-CPU 独立，无锁访问

kern_sync — 同步原语

  • Spinlock：__sync_lock_test_and_set + 内存屏障
  • Mutex：递归锁 + 优先级继承
  • Semaphore：原子计数 + 等待队列

kern_timer — 定时器系统

  • SysTick：CCOMPARE0 定时器，1kHz
  • 抢占：ISR 设置 need_resched 标志
  • 软件定时器：排序链表

kern_smp — 双核管理

  • Core 0 启动 Core 1
  • IPI 核间中断：跨核 reschedule / task kill
  • 任务 affinity mask

kern_sleep — 睡眠/唤醒

  • kern_sleep_ms(ms)：任务标记 SLEEPING
  • 排序唤醒链表，每 tick 检查头部
  • 替代所有 vTaskDelay 调用
